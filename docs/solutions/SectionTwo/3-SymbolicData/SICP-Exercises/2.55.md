## Follow Up
Why the interpreter prints 'quote with the expression (car ''abracadabra)?

## Pivot
Let's follow the substitution:
'abracadabra = (quote abracadabra)
''abracadabra = '(quote abracadabra) list expression with symbols. quote is a special form
so (car ''abracadabra) = (car '(quote abracadabra)) = 'quote
