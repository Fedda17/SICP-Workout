## Follow Up
Suppose 
``` racket
(define x (list 1 2 3))
(define y (list 4 5 6))
```
what the interpreter prints with these expressions?
``` racket
(append x y)
(cons x y)
(list x y)
```

## Pivot
I think the first one is simple enough:  
(1 2 3 4 5 6)  
The second one:  
((1 2 3) 4 5 6)

because (cons x y) = (cons (cons 1 (cons 2 (cons 3 nil))) (cons 4 (cons 5 (cons 6 nil))))

the third one is  
((1 2 3) (4 5 6))
