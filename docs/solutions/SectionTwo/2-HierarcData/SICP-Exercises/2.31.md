## Follow Up
An extension of the previous exercise. Put an abstraction barrier to the map-recursive definition approach on trees structures:
Example: 
``` racket
 (define (square-tree tree)
(tree-map square tree))

(define (tree-map op tree)
    (map (lambda (sub-tree) (if (pair? sub-tree) (tree-map op sub-tree) (op tree))) tree)
)
```
