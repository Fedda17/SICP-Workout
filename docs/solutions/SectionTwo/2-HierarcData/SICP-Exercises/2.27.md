## Follow Up
This exercise asks me to modify my reverse procedure in order to invert the elements in a list and 
invert the order of the elements if they're list:

(reverse x)  
((3 4) (1 2))  

(deep-reverse x)  
((4 3) (2 1))

## Follow Up
My reverse procedure is:
``` racket
(define (reverse l)
    (define (i-element i)
        (if (= (- (length l) i) -1 ) '()
            (cons (list-ref l (- (length l) i))  (i-element (+ i 1)))
        )
    )
    (i-element 1)
)
```

Honestly, I don't it it will work with elements as lists...

TEST RESULT --- NEGATIVE
It works because it doesn't suppose that the element is a primitive data.


## First Attempt
So, supposing this procedure is valid, in order to implement the procedure as required, I have to check if the element is a list and do the operation recursively:

``` racket
(define (deep-reverse l)
    (define (i-element i)
        (cond ((= (- (length l) i) -1 ) '())
              ((list? (list-ref l (- i 1))) (reverse (list-ref l (- i 1))))
              (else (cons (list-ref l (- (length l) i))  (i-element (+ i 1))))
        )
    )
    (i-element 1)
)
```

TEST RESULT --- NEGATIVE
 (deep-reverse x)
