## Follow Up
multi points exercise regarding the abstraction of a thing called a binary mobile.
Description of a binary mobile:
two branches, each branch has a length and something hanging.
It can be a weight or another binary mobile.

Constructors are provided:
``` racket
(define (make-mobile left right)
  (list left right))

(define (make-branch length structure)
  (list length structure))
```

## First Part
First point requires selectors for branch and binary mobile:

``` racket
(define (right-branch mobile) (list-ref mobile 0))
(define (left-branch mobile) (list-ref mobile 1))

(define (branch-length branch) (list-ref branch 0))
(define (branch-structure branch) (list-ref branch 1))
```


## Second Part
Second point requires a total weight procedure for a mobile:

``` racket
(define (total-weight mobile)
        (cond ((number? mobile) mobile)
              (else (+ (total-weight (branch-structure (right-branch mobile))) (total-weight (branch-structure (left-branch mobile)))))
        )
)
```

## Third Part
Third point requires a definition of a procedure that's a predicate to test when the mobile is balanced.
A mobile is balanced when the length of the left rod multiplied by the weight hanging from that rod is equal to the one from the right side
AND each submobile must be balanced as well.

``` racket
(define (balanced? mobile)
      (if (number? mobile) #t
         (and (= (* (branch-length (left-branch mobile)) (total-weight (branch-structure (left-branch mobile)))) 
                  (* (branch-length (right-branch mobile)) (total-weight (branch-structure (right-branch mobile)))))
            (balanced? (branch-structure (left-branch mobile))) (balanced? (branch-structure (right-branch mobile)))))
)
```

``` racket
(define (make-mobile left right)
  (cons left right))
```

``` racket

(define (left-branch mobile) (car mobile))
```
