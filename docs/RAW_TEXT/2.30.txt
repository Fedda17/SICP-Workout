This exercise asks me to make a procedure that square elements of a tree using basic operations for a definition and map and recursion for the other.


Example of application:
(square-tree
 (list 1
       (list 2 (list 3 4) 5)
       (list 6 7)))
(1 (4 (9 16) 25) (36 49))


(define (square-tree tree)
    (cond ((empty? tree) '())
            ((not (pair? tree)) (* tree tree))
            (else (cons (square-tree (car tree)) (square-tree (cdr tree)))))
)
